# Vision Screening Prototype v2

https://eyework-net.github.io/vision-screening-prototype/

視機能スクリーニング用に試作した Web ベースの検査プロトタイプです。  
2019年頃に着想していた「視力が低下すると見えやすくなる画像」を、ブラウザ上で連続的に調整・検証できる形として再構築しました。

本プロトタイプは完成版ではなく、**刺激設計・操作感・検査概念を確認するための備忘録的試作版**です。

---

## 概要

低周波ターゲット画像に対して、高周波マスキング刺激（矩形波ノイズ）を重ね、背景コントラストを変化させながら視認性を確認します。

従来の視力検査が「どこまで見えるか（最小可読閾）」を測るのに対し、本試作は、

- 一定条件で見えるか / 見えないか
- スクリーニング用途に転用できないか
- マスキング条件で視認性がどう変わるか

といった方向性を模索する目的で作成しています。

---

## 主な機能

- 背景コントラスト調整
- ターゲットサイズ変更
- マスク条件切替

  - ノイズなし
  - 矩形波ノイズ（粗）
  - 矩形波ノイズ（中）
  - 矩形波ノイズ（細）

- マスク強度調整
- 試行ログ表示
- CSV出力

## 現時点での課題

本バージョンはプロトタイプのため、以下は未対応です。

- 視角キャリブレーション
- 端末差補正（画面サイズ・解像度）
- 視距離管理
- 自動閾値探索
- staircase法
- catch trial
- test-retest 信頼性評価
- 刺激条件の統計的最適化

---

## 開発メモ

本ツールの本質は「視力検査の代替」ではなく、

**multi-scale masking stimulus を用いた視機能スクリーニング課題**

として再定義できる可能性があります。

今後の方向性としては、

1. 現場向け pass / fail スクリーニング版  
2. contrast threshold 測定版  
3. psychophysics ベース研究版  

への分岐を想定しています。
